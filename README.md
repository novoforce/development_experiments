# Dev Playground

A personal space for study notes, experiments, and hands-on learning across AI and software development.

## What's in here?

This repo is organized by topic. Each folder contains notes, code experiments, or mini-projects related to that area.

| Folder | What it will contain |
|---|---|
| `ai/` | AI concepts, model experiments, prompt engineering notes |
| `software-dev/` | General software development learning — patterns, tools, languages |
| `notebooks/` | Jupyter notebooks for data, ML, or API experiments |
| `snippets/` | Useful code snippets worth saving |

> Folders will be created as topics are added.

## Purpose

- Document what I learn as I go
- Keep small experiments and prototypes in one place
- Build a personal reference I can look back on

## How I use this

- Notes are written in plain Markdown — easy to read and search
- Each experiment lives in its own subfolder with a short README explaining what it does
- No strict structure — it grows naturally over time
